Isolation

Each agent connects with its own role. The database refuses anything else.

CREATE ROLE agent_trace LOGIN; GRANT SELECT ON traces TO agent_trace; CREATE ROLE agent_metric LOGIN; GRANT SELECT ON metrics TO agent_metric; CREATE ROLE agent_log LOGIN; GRANT SELECT ON logs TO agent_log; REVOKE ALL ON SCHEMA public FROM PUBLIC;

agent_metric querying the logs table returns InsufficientPrivilege. That failure is the test we run in week one.

About this console

Demo build

Telemetry here is generated, not collected. The incident logic matches the real system: agents read one signal each, exchange summaries rather than rows, and a diagnosis is written only when two independent agents agree above the threshold.

Cutting a link is the experiment that matters. The system should stop rather than guess.
